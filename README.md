Структура проєкту
app/
  main.py            # створення застосунку, роутери, lifespan (запуск фонової задачі)
  core/              # config.py (налаштування з .env), security.py (паролі, JWT)
  db/                # base.py (Base, TimestampMixin), session.py (engine, сесії)
  models/            # User, Task, Comment, enum-и статусів і пріоритетів
  schemas/           # Pydantic-схеми запитів і відповідей
  services/          # уся бізнес-логіка (auth, tasks, comments, overdue)
  api/
    deps.py          # get_db, get_current_user
    routers/         # auth, tasks, comments (тонкі, лише викликають сервіси)
alembic/             # міграції
tests/               # pytest

Роутери тільки приймають запит і викликають сервіс. Усі правила живуть у services/. Так легше змінювати логіку і залишати суть коду такою як і була
Тести використовують окрему базу task_manager_test. 
Вона очищається при кожному запуску, тому основну базу для тестів не використовувати

Редагувати і видаляти задачу може лише автор. Змінювати статус може автор або виконавець. Читати задачі і коментувати може будь-який залогінений користувач.

Якщо в дедлайні немає timezone тоді вона буде вважатись UTC.
